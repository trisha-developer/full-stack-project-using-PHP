# 🎬 CinemaBook

CinemaBook is a simple movie ticket booking website developed using PHP and MySQL.

## 📌 About

CinemaBook allows users to register, log in, browse movies, and book movie tickets through a simple web interface.

## ✨ Features

* User Registration & Login
* Email OTP Verification
* Movie Listing
* Movie Ticket Booking
* My Bookings
* User Settings
* Logout
* MySQL Database

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* PHP
* MySQL
* XAMPP
* PHPMailer

## ⚙️ How to Run

1. Install XAMPP.
2. Copy the project folder into the `htdocs` folder.
3. Start Apache and MySQL from XAMPP.
4. Create the CinemaBook database in phpMyAdmin.
5. Import the required database tables.
6. Open the project in your browser:
